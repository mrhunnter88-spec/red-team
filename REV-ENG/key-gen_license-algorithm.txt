
Anatomy of a Professional License Key

Modern license keys are generally divided into two main components:
1. The Payload (Data): Contains unencrypted or base64-encoded metadata (e.g., Expiration Date, Features Allowed, User ID).
2. The Cryptographic Signature: A cryptographic hash of the payload, signed using an Asymmetric Private Key (RSA, ECC). The application contains the corresponding Public Key to verify that the payload was not altered.

Step-by-Step Reverse Engineering of Modern Key Checks


1. Identify the Verification Method

If you open the binary in a decompiler and search for cryptographic signatures, look for:
• Large byte arrays containing distinct patterns (e.g., -----BEGIN PUBLIC KEY-----).
• References to crypto libraries like OpenSSL, Windows CryptoAPI, or BCrypt.

2. Spot the Vulnerability / Bypassing Strategy

Because you do not possess the developer's private key, you cannot generate a mathematically valid signature for a custom license name using their original system. To bypass this, reverse engineers use Public Key Replacement (Patching):
• Locate the hardcoded public key inside the binary.
• Generate your own private/public key pair.
• Patch the binary by overwriting the developer's public key with your new public key.
• Use your custom private key to sign any license payload you want. The patched binary will accept it as authentic.

Step 2: The Keygen and Verification Code

python
import base64
import json
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes, serialization

# ==========================================
# 1. SETUP: DEVELOPER KEY GENERATION
# ==========================================
# The developer keeps the private key secure on their server to build the keygen.
# The public key is hardcoded directly inside the distributed desktop software.
private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
public_key = private_key.public_key()


# ==========================================
# 2. THE KEYGEN ALGORITHM (Server Side)
# ==========================================
def generate_license_key(user_email: str, expiry_date: str, features: list) -> str:
    """
    Generates a cryptographically signed license key string.
    """
    # Create the license payload data structure
    payload_dict = {
        "email": user_email,
        "expires": expiry_date,
        "features": features
    }
    
    # Serialize the payload dictionary to a compact JSON byte string
    payload_bytes = json.dumps(payload_dict, sort_keys=True).encode('utf-8')
    
    # Sign the payload using the private key
    signature = private_key.sign(
        payload_bytes,
        padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH),
        hashes.SHA256()
    )
    
    # Bundle payload data and signature into a single transportable string structure
    license_data = {
        "data": base64.b64encode(payload_bytes).decode('utf-8'),
        "signature": base64.b64encode(signature).decode('utf-8')
    }
    
    # Return as a clean, base64 encoded license key block
    final_key = base64.b64encode(json.dumps(license_data).encode('utf-8')).decode('utf-8')
    return final_key


# ==========================================
# 3. THE LICENSE CHECK ROUTINE (Client Side)
# ==========================================
def verify_license_key(license_key_string: str) -> dict:
    """
    Decodes the key and validates the signature using the embedded public key.
    """
    try:
        # Decode the main outer envelope
        envelope = json.loads(base64.b64decode(license_key_string.encode('utf-8')).decode('utf-8'))
        
        # Extract the structural parts
        payload_bytes = base64.b64decode(envelope["data"].encode('utf-8'))
        signature_bytes = base64.b64decode(envelope["signature"].encode('utf-8'))
        
        # Cryptographically verify the data against the public key
        public_key.verify(
            signature_bytes,
            payload_bytes,
            padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH),
            hashes.SHA256()
        )
        
        # If no error is raised, the key integrity is genuine. Read the features safely.
        license_info = json.loads(payload_bytes.decode('utf-8'))
        return {"status": "SUCCESS", "details": license_info}
        
    except Exception as e:
        return {"status": "INVALID", "reason": "Signature verification failed or corrupted data."}


# ==========================================
# DEMONSTRATION RUN
# ==========================================
if __name__ == "__main__":
    print("[*] Simulating Server-Side Keygen generation...")
    # Generate a key for a user
    license_key = generate_license_key(
        user_email="premium_buyer@example.com",
        expiry_date="2030-12-31",
        features=["pro_tools", "offline_mode"]
    )
    print(f"[+] Issued License Key Block:\n{license_key}\n")
    
    print("[*] Simulating Local Desktop App License Validation...")
    # App reads the string and passes it into the internal validation routine
    validation_result = verify_license_key(license_key)
    print(f"[+] Verification Result: {validation_result}")

Hardware-Locked License Keys (HWID)

To stop users from sharing a valid license key with friends, keygens often require a Hardware ID (HWID). The keygen incorporates the buyer's unique HWID directly into the signed payload.
When the application launches, it checks the local machine specs to see if they match the data signed inside the key.

Common Python HWID Gathering Strategy

python
import hashlib
import platform
import subprocess

def get_machine_hwid() -> str:
    """
    Gathers unique, permanent hardware indicators to create a static HWID fingerprint.
    """
    # Combine core hardware properties
    system_info = f"{platform.processor()}-{platform.machine()}"
    
    # Try fetching motherboard UUID on Windows
    if platform.system() == "Windows":
        try:
            uuid_output = subprocess.check_output("wmic csproduct get uuid").decode().split("\n")[1].strip()
            system_info += f"-{uuid_output}"
        except Exception:
            pass
            
    # Hash the resulting string into a uniform, readable format
    return hashlib.sha256(system_info.encode()).hexdigest()[:16].upper()

print(f"Current Machine HWID for licensing: {get_machine_hwid()}")
