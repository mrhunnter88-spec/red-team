
🎨 The Three Core Direction Finding Methodologies

Modern wireless auditing and radio direction finding (RDF) systems leverage three main hardware and algorithmic approaches:

RDF Methodology	Physical Mechanism	Technical Implementation
Switched/Rotational Yagi (Macho)	The operator physically or mechanically rotates a highly directional antenna (like a Yagi-Uda or parabolic dish) until the signal's amplitude hits its absolute highest peak.	Single radio channel tracking; manually mapping the highest Received Signal Strength Indicator (RSSI) vector.
Pseudo-Doppler Array	An automated controller rapidly samples a circular ring of multiple omnidirectional antennas. This switching creates an artificial Doppler frequency shift in the received signal.	The phase shift of the Doppler modulation matches the precise inbound wave direction.
Phased-Array Interferometry	Measures the subtle Phase Difference (\(\Delta \psi\)) of an incoming wavefront hitting two or more stationary antennas spaced closely together.	Uses advanced digital signal processing algorithms like MUSIC (Multiple Signal Classification) or ESPRIT.


🧠 The Interferometry Mathematical Puzzle

When a radio wave hits an antenna array at an angle (\(\theta \)), it arrives at one element slightly before the other. This spatial offset creates a predictable phase difference (\(\Delta \psi\)) between the two antenna signals:
\(\Delta \psi =\frac{2\pi \cdot d\cdot \sin (\theta )}{\lambda }\)
Where:
• \(d\) = The exact spacing distance between the antenna elements (typically fixed at exactly half the target's wavelength: \(\lambda / 2\)).
• \(\lambda \) = The wavelength of the incoming carrier frequency (\(c / \text{frequency}\)).
• \(\theta \) = The True Angle of Arrival (AoA).
By rearranging this equation, your digital signal processing engine can solve for the unknown direction angle directly from the measured phase difference:
\(\theta =\arcsin \left(\frac{\Delta \psi \cdot \lambda }{2\pi \cdot d}\right)\)

💻 Python Code: Resolving Angle of Arrival (AoA) via Phase Shift

The following diagnostic script simulates an automated dual-antenna receiver system. It captures raw complex IQ samples from two hardware elements separated by half a wavelength, calculates the relative phase difference between their signals, and outputs the exact inbound direction angle of the transmitter.
python
import numpy as np

def resolve_angle_of_arrival(iq_samples_ant1, iq_samples_ant2, frequency):
    """
    Calculates the exact physical Angle of Arrival (AoA) of an incoming 
    wireless wave using two-element phase interferometry.
    """
    SPEED_OF_LIGHT = 299792458.0  # m/s
    
    # 1. Compute the wavelength (lambda) of the target frequency
    wavelength = SPEED_OF_LIGHT / frequency
    
    # 2. Maintain structural spacing at exactly half a wavelength
    antenna_spacing_d = wavelength / 2
    
    print(f"[*] Analyzing target carrier: {frequency / 1e6:.2f} MHz (Wavelength: {wavelength:.3f}m)")
    print(f"[*] Configured antenna element spacing: {antenna_spacing_d:.3f}m")

    # 3. Compute cross-correlation to isolate the average phase delta
    # Multiplying sample array 1 by the complex conjugate of array 2 extracts the angular shift
    cross_correlation = np.mean(iq_samples_ant1 * np.conj(iq_samples_ant2))
    phase_difference = np.angle(cross_correlation) # Returns phase delta in radians (-pi to +pi)
    
    # 4. Apply the inverse trigonometric interferometer formula to resolve theta
    # Clamp the inner calculation to [-1.0, 1.0] to prevent mathematical floating errors
    inner_val = (phase_difference * wavelength) / (2 * np.pi * antenna_spacing_d)
    inner_val = np.clip(inner_val, -1.0, 1.0)
    
    angle_radians = np.arcsin(inner_val)
    angle_degrees = np.degrees(angle_radians)
    
    print("\n[🎯 Antenna Direction Finder Solved]:")
    print(f" ├── Measured Phase Shift (Δψ): {phase_difference:+.4f} radians")
    print(f" └── Resolved Angle of Arrival (AoA): {angle_degrees:+.2f}°")
    
    return angle_degrees

if __name__ == "__main__":
    # --- PHYSICAL RADIO SIMULATION CONFIGURATION ---
    TARGET_FREQ = 2412e6  # Auditing a standard 2.4 GHz Wi-Fi signal (Channel 1)
    
    # Simulate a rogue transmitter beaming a signal from an explicit angle of +35 degrees
    SIMULATED_AOA_DEGREES = 35.0
    simulated_aoa_rad = np.radians(SIMULATED_AOA_DEGREES)
    
    # Calculate the theoretical physics-based phase difference that should occur over the air
    # Delta_Psi = (2 * pi * d * sin(theta)) / lambda | Since d = lambda/2 -> Delta_Psi = pi * sin(theta)
    expected_phase_shift = np.pi * np.sin(simulated_aoa_rad)
    
    # Synthesize time vectors and clean baseband sine waves
    t = np.linspace(0, 0.001, 1000)
    base_wave = np.exp(1j * 2 * np.pi * 1000 * t) # 1 kHz test intermediate frequency
    
    # Antenna 1 serves as our stationary reference point
    antenna_1_iq = base_wave
    
    # Antenna 2 receives the wave shifted by our calculated spatial phase delta
    antenna_2_iq = base_wave * np.exp(1j * expected_phase_shift)
    
    # Inject atmospheric background thermal noise onto both channels
    noise_1 = (np.random.normal(0, 0.1, len(t)) + 1j * np.random.normal(0, 0.1, len(t)))
    noise_2 = (np.random.normal(0, 0.1, len(t)) + 1j * np.random.normal(0, 0.1, len(t)))
    
    dirty_ant1 = antenna_1_iq + noise_1
    dirty_ant2 = antenna_2_iq + noise_2

    # Execute the digital signal processing direction pipeline
    resolve_angle_of_arrival(dirty_ant1, dirty_ant2, TARGET_FREQ)

When a device transmits on their restricted airspace, the system doesn't just read the packet contents; it maps the precise physical incoming path angle. If the transmission vector originates from outside the legitimate office space (e.g., from a vehicle parked across the street), the firewall drops the session token and alerts perimeter security.
