
🎨 The Mathematical Concepts: TDOA vs. RSSI


Tracking Metric	Core Operating Concept	Environmental Constraints
RSSI Triangulation (Trilateration)	Uses the log-distance path loss model to convert the received signal power (dBm) into an estimated distance vector.	Highly Volatile: Signal attenuation fluctuates wildly due to concrete walls, weather, and physical obstacles.
TDOA (Hyperbolic Positioning)	Measures the literal nanosecond difference in a wave's arrival time across three or more synchronized receiver stations.	Extremely Precise: Independent of signal amplitude, but requires microsecond-level clock sync (like GPS/GNSS clocks).


🧠 The TDOA Mathematical Puzzle

Because radio waves travel at the speed of light (\(c \approx 3 \times 10^8 \text{ m/s}\)), if a rogue access point transmits a packet, the signal will hit closer sensor stations slightly earlier than distant ones.
Measuring the time delta (\(\Delta t\)) between any two sensors creates a constant difference in distance (\(\Delta d = c \cdot \Delta t\)). Geometrically, plotting all possible points with a constant distance difference between two fixed focuses yields a Hyperbola. By utilizing three or more receiver nodes, the intersection of these hyperbolas pinpoints the exact coordinates of the transmitter.

💻 Python Code: Hyperbolic TDOA Location Intersect Engine

The following script models an offline signal location engine. It takes the fixed coordinate points of three listening sensor arrays (anchors) and the nanosecond arrival deltas of an intercepted packet to resolve the spatial coordinates of the rogue transmitter.

import numpy as np
from scipy.optimize import minimize

def calculate_tdoa_emitter_position(anchor_coords, time_deltas):
    """
    Resolves the exact 2D coordinates of an unknown emitter using 
    Time Difference of Arrival (TDOA) least-squares optimization.
    
    anchor_coords: List of (x, y) tuples for the listening stations
    time_deltas: Time differences relative to Anchor 0 in seconds [t1-t0, t2-t0]
    """
    SPEED_OF_LIGHT = 299792458.0  # meters per second
    
    # Convert time deltas to physical distance differences (meters)
    distance_deltas = np.array(time_deltas) * SPEED_OF_LIGHT
    
    # Target function: Calculates error between guess coordinate and anchor distances
    def error_function(guess_xy):
        x, y = guess_xy
        
        # Calculate distance from guess coordinate to the baseline Anchor 0
        d0 = np.sqrt((x - anchor_coords[0][0])**2 + (y - anchor_coords[0][1])**2)
        
        # Calculate theoretical distance deltas for remaining anchors
        errors = []
        for i in range(1, len(anchor_coords)):
            di = np.sqrt((x - anchor_coords[i][0])**2 + (y - anchor_coords[i][1])**2)
            theoretical_delta = di - d0
            
            # Error = (Reality - Theory)^2
            errors.append((distance_deltas[i-1] - theoretical_delta) ** 2)
            
        return sum(errors)

    # Begin optimization sequence from the spatial center of the anchors
    initial_guess = np.mean(anchor_coords, axis=0)
    
    # Minimize the error function using Nelder-Mead optimization
    result = minimize(error_function, initial_guess, method='Nelder-Mead')
    
    resolved_x, resolved_y = result.x
    print(f"\n[🎯 TDOA Location Engine Solved]:")
    print(f" ├── Anchor 0 Baseline Pos:  X: {anchor_coords[0][0]}, Y: {anchor_coords[0][1]}")
    print(f" ├── Intercepted Time Deltas: Δt1: {time_deltas[0]*1e9:.2f} ns | Δt2: {time_deltas[1]*1e9:.2f} ns")
    print(f" └── Resolved Emitter Location: X: {resolved_x:.2f} meters, Y: {resolved_y:.2f} meters")
    
    return resolved_x, resolved_y

    t1_minus_t0 = (d1 - d0) / SOL

    simulated_deltas = [t1_minus_t0, t2_minus_t0]
